**Notifinancia - Gestão de Investimentos e Estudo sobre Apostas Online**
  - Este repositório contém os recursos, códigos e análises desenvolvidos para o Trabalho de Conclusão de Curso (TCC) intitulado: "UTILIZAÇÃO DE JOGOS DE APOSTAS ONLINE POR DISCENTES DO ENSINO SUPERIOR: UM ESTUDO DE CASO NA UNIVERSIDADE FEDERAL DO SEMI-ÁRIDO (UFERSA)".
  
 - O projeto combina uma pesquisa quantitativa sobre o comportamento financeiro discente com o desenvolvimento da ferramenta Notifinancia, que visa oferecer uma alternativa segura e educacional ao mercado de apostas de risco.

**Status: Protótipo Funcional / Em Desenvolvimento**
**🎯 Objetivo do Projeto**
-  O objetivo geral é analisar a utilização de plataformas de jogos de apostas online pelos discentes da UFERSA (Campus Angicos) e fornecer a ferramenta Notifinancia como um suporte para converter o interesse em "ganhos rápidos" em uma cultura de investimento sólido e planejado.

**Atividades Propostas**
-  [x] Coleta de dados via Survey (Perfil sociodemográfico e acadêmico).
  
 - [x] Análise estatística de comportamentos de risco e motivações.
  
-  [x] Desenvolvimento do ecossistema de gestão de ativos (Notifinancia).
  
 - [x] Integração com APIs financeiras em tempo real.
  
-  [x] Automação de relatórios de performance via e-mail.

**🛠️ Tecnologias Utilizadas**
 - O projeto utiliza o ecossistema Google Cloud e tecnologias web modernas para garantir acessibilidade e baixo custo de manutenção:
  
-  Linguagem: Google AppScript (JavaScript/GAS)
  
-  Banco de Dados: Google Sheets (Persistência de dados relacionais)
  
 - Integrações: Google Finance API (Cotações) e Gmail Service (Notificações)
  
-  Frontend: HTML5, CSS3 (Tailwind CSS) e JavaScript
  
-  Análise de Dados: Microsoft Power BI (Visualização dos resultados da pesquisa)

**📊 Resultados da Pesquisa**
-  A pesquisa realizada no Campus Angicos revelou dados cruciais para a compreensão do cenário atual:
  
 - Perfil Econômico: 86% dos estudantes possuem renda familiar de até 2 salários mínimos.
  
 - Adesão às Apostas: 39,5% dos discentes afirmaram já ter utilizado plataformas de apostas.
  
-  Motivação: O fator financeiro é decisivo para 76,5% dos apostadores (busca por lucro ou renda extra).
  
-  Plataformas: A Betano consolidou-se como a "casa de aposta" mais utilizada (35,2%).
  
-  Interesse em Investir: Identificou-se uma demanda latente, onde 79% da amostra manifestou interesse ativo em aprender sobre finanças e investimentos reais.

**🚀 A Ferramenta Notifinancia**
-  O Notifinancia atua como um motor de transformação, transformando dados brutos de mercado em informações acionáveis para o investidor iniciante.
  
  Funcionalidades Principais:
  
-  Autenticação Segura: Login integrado via Google OAuth2.
  
-  Gestão de Carteira (CRUD): Controle de ativos da B3, preços médios e quantidades.
  
-  Monitoramento em Tempo Real: Comparação automática via Google Finance.
  
-  Relatórios Diários: Envio agendado (18h) com o resumo da performance diretamente no e-mail do usuário.
